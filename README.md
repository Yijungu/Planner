## 개요
**Planner**는 기존의 스케줄러 앱과는 차별화된, 사용자의 요구에 맞춘 스케줄 관리 기능을 제공하는 모바일 애플리케이션입니다. 이 앱은 마감일이 있는 업무와 이벤트성 업무를 유동적으로 관리할 수 있으며, 음성 명령을 통해 업무를 쉽게 등록할 수 있는 기능을 포함하고 있습니다.

## 프로젝트 목적
**Planner**는 기존 스케줄러 앱과는 다른 사용자 중심의 접근 방식을 도입해, 프로젝트 관리와 같은 복잡한 업무 스케줄을 손쉽게 관리할 수 있는 환경을 제공합니다. 특히, 마감일과 이벤트성 스케줄의 유동적인 관리가 가능하도록 설계되었습니다.

## 주요 업무

### 기획 및 연구
- **시장 조사**: 기존의 유사한 스케줄러 어플리케이션을 분석하고, 경쟁력을 갖춘 요구사항을 도출.
- **요구사항 정리**: 디자이너와 협력하여 차별화된 사용자 요구사항을 정의하고 정리.
- **구조 설계**: 새로운 스케줄 관리 애플리케이션의 기획 및 전체 구조 설계.

### 개발
- **데이터베이스 설계**: 마감일이 있는 스케줄과 이벤트성 스케줄의 유동적인 이동을 위한 데이터베이스 설계 및 구축.
- **로그인 과정 개발**: 사용자 인증을 위한 로그인 시스템 구현.
- **Prompt Engineering 및 파인튜닝**: 음성을 통한 업무 등록 알고리즘을 개발하기 위해 Prompt Engineering과 파인튜닝을 수행.
- **UI/UX 설계 및 인터랙션 구현**: 사용자의 경험을 극대화하기 위해 UI/UX를 설계하고 여러 인터랙션을 React Native로 구현.
- **음성 기반 스케줄 관리**: 프론트엔드에서 음성을 텍스트로 변환한 후, 백엔드에서는 고객을 상대하는 AI 에이전트와 데이터베이스를 관리하는 에이전트가 상호작용하여 사용자의 스케줄을 자동으로 관리하도록 설계. 이 구조는 고객 - 상담 에이전트 - 데이터베이스 관리 에이전트 간의 협업을 통해 데이터베이스가 관리되도록 구성되었습니다.

## 사용 기술
- **언어**: JavaScript
- **프레임워크 및 라이브러리**: React Native, Node.js
- **데이터베이스**: MongoDB
- **개발 도구**: Docker, iOS 개발 환경
- **주요 기능**: 음성 명령 기반 업무 등록, 유동적인 스케줄 관리

## 느낀 점
이 프로젝트를 통해 **UI/UX 설계와 음성 명령 기능**의 중요성을 깊이 이해했으며, **데이터 구조와 인터랙션을 체계적으로 관리**하는 방법을 학습하면서 더 효율적인 개발 방식을 고민하게 되었습니다. 특히, **컴포넌트와 레이아웃 간의 복잡한 인터랙션**을 구현하며, 향후 프로젝트에서 **더 깔끔하고 체계적인 개발**을 위한 좋은 경험을 쌓을 수 있었습니다. 현재, 음성 기반 스케줄 관리 기능의 경우 손익 계산 결과, 사업적 타당성이 부족하여 잠정 중단한 상태입니다.
